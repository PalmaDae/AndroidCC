Домашнее задание №1 - Activity & Intent
Дедлайн: 26.09 - 100%, 03.10 - 50%

Написать приложение, состоящее из трех экранов. На данный момент, каждый экран - это отдельная Activity
UI часть делается на Compose

Первый экран:
- Поле для ввода текста (вьюшка называется TextField)

- Первая кнопка - по нажатию открывать второй экран. Если в textField был введен какой-либо текст, передавать текст на второй экран и отображать его в текстовом поле

- Вторая кнопка - по нажатию открывать третий экран. Если с первого экрана был передан какой-либо текст, передавать его на третий экран

Второй экран:
- Поле для отображения текста (вьюшка Text). Если с первого экрана был передан какой-либо текст, отображать его в этом поле. Если текст не был передан, отображать какой-либо стандартный текст (например "Экран 2")

- Первая кнопка - по нажатию на кнопку открывать третий экран. Если с первого экрана был передан текст, прокидывать его дальше на третий экран

- Вторая кнопка - по нажатию на кнопку открывать первый экран. В стеке должен быть новый экземпляра активити с первым экраном

Третий экран:
- Поле для отображения текста. Если с первого / второго экрана был передан текст, отображать его в этом поле. Если текст не был передан, отображать какой-либо стандартный текст (например "Экран 3")

- Кнопка - по нажатию на кнопку, открывать первый экран. В стеке должен быть единственный экземпляр активити первого экрана

Что должно быть на скринкасте:
- Первый экран >> Нажимаете на кнопку перехода на второй экран >> Второй экран >> нажимаете на кнопку перехода на третий экран >> Третий экран >> жмете назад >> Второй экран >> жмете назад >> Первый экран >> вводите любой текст, жмете на кнопку перехода на второй экран >> жмете на кнопку перехода на третий экран >> Жмете на кнопку перехода на первый экран >> жмете кнопку назад
